# UseBy — Never Let Food Go to Waste

## About the Project

UseBy is an iOS application designed to help students and people living in shared apartments reduce food waste.

Users can add groceries by scanning barcodes, automatically estimate expiration dates, receive reminders before food expires, and discover recipes based on ingredients they already have.

Our goal is to make grocery management easier, reduce unnecessary food waste, and help users save money.

## Project Goals

- **Grocery Tracking:** Allow users to add and manage groceries through barcode scanning or manual entry.
- **Expiration Estimates:** Automatically estimate expiration dates using USDA FoodKeeper data.
- **Expiration Reminders:** Notify users when groceries are approaching their expiration dates.
- **Recipe Recommendations:** Suggest recipes that prioritize ingredients expiring soon.
- **Food Waste Reduction:** Encourage users to use their groceries before they go bad.
